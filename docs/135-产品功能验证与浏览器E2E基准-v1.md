## 1. 使用说明

### 1.1 运行形态（二选一）

- **容器（推荐，持久化 PG 档）**：`docker compose up --build` → http://localhost:8000；结束 `Ctrl+C`＋`docker compose down`（彻底清空 `down -v`）。
- **本地 dev（内存档）**：后端 `.venv/bin/uvicorn atlas.api.main:app --reload` ＋ 前端 `cd frontend && pnpm dev`（http://localhost:5174，代理到 8000）。数据重启即失，适合单轮验证。

### 1.2 账号与入口

| 角色 | 账号 | 说明 |
|---|---|---|
| 企业 A 管理员 | `admin-a` / `admin123` | 全功能（建/跑/审批/管理），默认用此 |
| 企业 A 运营 | `operator-a` / `operator123` | 跑流程、处置告警 |
| 企业 A 只读 | `viewer-a` / `viewer123` | 只读 |
| 模拟商家后台 | http://localhost:8000/demo/shop，`demo`/`demo` | 5 笔待处理退款单（12345–12349） |

前端页面（`frontend/src/App.tsx` 实核）：`dashboard` 工作台 / `editor` 流程编辑器 / `monitoring` 监控 / `memory` 记忆（记忆+知识双标签）/ `approvals` 审批 / `users` 用户 / `audit` 审计 / `openapi` OpenAPI 导入 / `waits` 等待 / `schedules` 调度 / `agents` 智能体 / `reflection` 反思 / `models` 模型 / `usage` 用量 / `templates` 模板 / `embeds` 嵌入配置 / `adapterDrafts` NL 造适配器 / `experiments` A/B 实验。

### 1.3 标记与 E2E 级别

- 每项：✅ 通过 / ❌ 不通过 / ⚠️ 部分通过，附备注与截图。
- **E2E 级别**（决定自动化方式）：
  - **L1**：浏览器全自动可验（导航→操作→断言，零外部依赖）。
  - **L2**：浏览器可操作但需造数/等待/人工判读（如 LLM 生成耗时、判据主观、样本量积累）。
  - **L3**：需外部资源/REST 注入（真实凭据、webhook、命令行），浏览器只做结果查验。

## 2. 核心主线（必验，产品灵魂）

### 1. 登录与多租户权限（L1）

- **入口**：`/`（登录页）
- **操作**：① `admin-a` 登录 → 断言进入工作台、可进编辑器；② 登出 → `viewer-a` 登录 → 断言编辑器/运行类写操作不可见或被拒（403 或按钮缺失）；③ 登出 → 错误密码 → 断言被拒。
- **断言**：三角色页面差异符合 RBAC；坏凭证不通过。

### 2. 自然语言生成流程（NL 生成）（L2）

- **入口**：`editor` → 顶部「自然语言生成」
- **操作**：输入 `收到退款申请后，让 AI 判断退款原因和金额，合理就自动退款，不合理就转人工。` → 等待（自测 15–25s，按钮转圈）→ 草稿载入画布。
- **断言**：画布出现 ≥3 节点且含「AI 决策/条件分流/双出口」结构、节点间有边；草稿可直接编译。

### 3. 画布编排与编译校验（L1）

- **入口**：`editor`
- **操作**：① 拖「条件分支」「人机协作」到画布并连线；② 在 AI 节点提示词插入 `{{trigger-1.context.payload.amount}}`；③ 制造非法连线（如 target 不存在）→ 点「编译」。
- **断言**：拖拽/配置即时生效；非法图编译报结构化错误（前端 Problems 面板同步提示），不静默放行；合法变量插值可保存。

### 4. 一键运行与实时可视化（SSE）（L1）

- **入口**：`editor` → 顶部运行区
- **操作**：载入内置「退款审核」模板（或 NL 草稿）→ 选退款单 **12345**（¥299，商品破损）→ 「编译并运行」。
- **断言**：节点随执行依次亮起；弹窗含运行结果 JSON；`ai_decision-1.decision.reason` 有判断理由；自测 7–8s 出结果。

### 5. AI 决策 + 条件分流（L2）

- **入口**：同上
- **操作**：换单 **12346**（¥5000，不想要了）再跑。
- **断言**：12346 走「转人工」分支（未自动退款）；与 12345（自动退款）对比分支不同；AI 理由与分流结果一致。

### 6. 人机审批（真挂起→队列→通过/拒绝）（L1）

- **入口**：`approvals` 页；`editor` 运行
- **前置**：内置退款模板（D57 后已含 `human_approval` 真挂起——AI 判转人工即挂起，非 TRIAL.md 旧描述）
- **操作**：① 跑一笔判转人工的单（如 12346）→ SSE 停在审批节点；② 打开「审批」页 → 断言出现待办（订单/金额/理由）；③ 点「通过」→ 断言运行继续走「人工审批通过→执行退款」分支；④ 再跑一笔点「拒绝」→ 走「拒绝退款」分支；⑤ 对已决审批重复决策。
- **断言**：挂起真实等待、决策后继续且分支正确、重复决策 409。

### 7. 适配器执行闭环（业务对账）（L1）

- **入口**：`/demo/shop`（模拟商家后台）
- **操作**：跑 12345 自动退款成功后 → 打开商店后台 `demo`/`demo` → 点「刷新」。
- **断言**：12345 从「待处理」移到「AI 已处置」并标「AI 已自动退款」+理由；人工通过的单标「人工审批通过」；转人工未批的单标「AI 转人工」。

### 8. 高级编排：循环/并行/等待/子图（L1）

- **入口**：`editor`（新建图）
- **操作**：搭「触发 → 循环(loop, 最大 3) → 并行(parallel 两分支) → 等待(wait 2s) → 子图(subgraph 引用另一张已存图) → 结束」→ 编译运行。
- **断言**：循环按配置转圈、并行分支并发执行并汇聚、wait 到时继续、子图被引用执行且结果回传；编译期拦截子图缺失/环等错误。

## 3. 运营与发布（进阶，选验）

### 9. 发布/灰度/指标门控回滚（L2）

- **入口**：`editor` 发布流；`monitoring` 验证
- **操作**：改已发布图配置 → 发布 → 设 canary 比例（如 10%）→ 连续跑多笔观察分流 → 到监控页看指标。
- **断言**：发布走版本化；灰度按比例分流不一步全量；指标越阈自动回滚（运行记录可见 `actor="auto"`）。

### 10. A/B 实验对照判定（L2）

- **入口**：`experiments`
- **操作**：创建实验（stable/candidate 双版本、流量比例、指标如退款差额率）→ 跑 ≥30 笔积累样本 → 查看判定。
- **断言**：能创建/分流；样本足够时给两比例 z 检验胜出结论；conclude 走 promote/rollback；同图至多一个 running 实验。

### 11. 模板库（L1）

- **入口**：`templates`
- **操作**：从模板新建（退款自动审批/HTTP 订单分支/SQL 查询通知等）→ 载入画布。
- **断言**：模板一键载入、零配置直接编译运行。

### 12. 监控与告警中心（L1）

- **入口**：`monitoring`
- **操作**：看指标六卡与最近运行；跑一个失败流程（指向不存在工具）→ 看告警。
- **断言**：指标按运行/节点聚合；失败产生告警、可 acknowledge/resolve；规则阈值可调。

### 13. LLM 用量计量（L1）

- **入口**：`usage`
- **操作**：跑 2–3 个流程 → 打开「用量」按模型/天/图看汇总。
- **断言**：用量按模型/租户/图/日聚合且明细一致；本地演示档 reset 后账清空。

## 4. 智能与进化（进阶，选验）

### 14. 反思进化：候选→采纳→自动生效（L2）

- **入口**：`reflection`
- **操作**：查看进化候选（图参数/节点配置类）→ 对一个候选执行「自动生效」→ 观察证据链（影子→黄金回放→发布→灰度→门控回滚）→ 任一步「中止」。
- **断言**：候选可见/可采纳驳回；自动生效走完整推进链且每步留证据；可随时中止；只自动生效图内参数类（结构类恒不自动）。

### 15. 自走循环 Loop（L2）

- **入口**：`editor`（图配置启用 `loop`）；同步运行
- **操作**：启用 loop（设最大迭代/墙钟/token 预算与终止条件）→ 同步运行 → 观察多圈；设极小预算（1 圈）验证触顶即停。
- **断言**：一圈＝一次真实图执行连续 N 圈；任一预算闸门触顶即终止并记原因；停止分「停一圈/停整条圈」。

### 16. 智能体团队面（L1）

- **入口**：`agents`
- **操作**：跑若干流程（可挂 agent）→ 打开「智能体」查看各 agent 执行日记与 Token 汇总。
- **断言**：agent 列表可查；每个 agent 有运行记录与 token 消耗（走 usage 账）；可启停。

### 17. 记忆与知识库（L1）

- **入口**：`memory`（记忆/知识双标签）
- **操作**：① 通过工具/页面写入一条记忆（`memory/remember`，fact 或 preference）→ 页面可见；② 跑一条 `memory/recall` 流程验证取回；③ 「知识」标签导入一段纯文本 → `memory/recall` 带类别过滤验证命中。
- **断言**：记忆可写可读、分类正确；知识导入后按类别召回。

## 5. 自动化与扩展（按需）

### 18. 机器人试教：录制→回放→成图→操作指引（L2）

- **入口**：`editor` 运行录制；录制用例管理
- **操作**：运行流程并录制 → 打开录制回放（断言逐节点比对一致）→ 对用例执行「生成图」→ 草稿进编辑器人工放行 → 请求该用例「操作指引」预览。
- **断言**：回放通过率 100%；成图草稿可编辑且**必须人工放行**（不自动发布）；指引为只读产物、脱敏复用 loader 同源实现。

### 19. 单步调试与断点（L1）

- **入口**：`editor` Header「调试」
- **操作**：开启调试 → 设节点断点（可条件断点）→ 逐步执行 → 查看变量只读快照。
- **断言**：逐节点暂停/继续、断点命中、变量快照只读、停止只在暂停点生效。

### 20. 网页嵌入（公开只读面）（L1）

- **入口**：`embeds` 配置；`/embed/{token}` 公开页
- **操作**：对已发布图签发嵌入短链 → 无登录新窗口打开 `/embed/{token}` → 再试篡改 token。
- **断言**：公开页只展示图元信息（节点数/变量/最近运行摘要），无密钥/决策/草稿；篡改 token 一律 404。

### 21. 入站会话触发（L3）

- **入口**：REST `POST /api/channels/inbound/{binding_id}`；`approvals`/会话视图
- **前置**：配置渠道 binding 映射（`inbound-mappings`）
- **操作**：向绑定地址发一条消息触发 `message_inbound` 流程 → 查看会话记录与产出 → 重复发同一条。
- **断言**：验签通过触发一次 run；重复消息幂等去重；失败进死信可查；输出回写原会话。

### 22. 离线批评估（AI 评估 Harness）（L3）

- **入口**：REST `POST /api/evaluations`＋`GET /api/evaluations`
- **操作**：创建评估任务（测试用例＋预期行为/验证表达式）→ 跑批评估 → 查看指标三元组。
- **断言**：任务可创建/查询；批评估跑完整图链路；失败用例可定位。

**E2E 环境事实**：`localhost:8000` 后端为 loom/infra 部署（容器 `infra-backend`，端口 8000），**其镜像不含打包 BN（D69）圈层**——容器内 `/openapi.json` 无任何 `cycle` 路径，故 `POST /run` 配置 loop 后仍单圈、`GET /api/runs/{id}/cycle` 404（FastAPI 路由不存在，非 `CYCLE_NOT_FOUND`）。**本地 atlas 源码 BN 接线完整**（`cycles/{supervisor,state,judge}.py` ＋ `GraphDSL.loop` 校验 ＋ `main.py` 同步 `/run` 经 `run_cycle_session` 驱动；docs/14 D69 行已收口）。⇒ 第 8 项复验前必须先确认/重建后端到含 BN 的代码版本。

**发现项（清单断言 vs 实际 UI/环境偏差，复验时优先处理）**：
