# Atlas 反馈工作流

> **用途**：用户与 AI 协作者之间的高效反馈方式，参照 agent-world 惯例。适用于任何会话。

## 一、看到不爽 / 想要修改

1. **截图 + 一句话标签**：截屏后加 ≤6 字的问题标签（如「按钮错位」「文案太啰嗦」），发给协作者。一张截图配一个标签，一次只反馈一件事。
2. **描述位置**：说明在哪个界面/哪份文档/哪个流程里看到的，便于定位。
3. **想要的效果**：如有明确预期，一句话说清（如「改成左对齐」「删掉第三节」）。

## 二、想让 AI 看你的电脑 / 浏览器

- 说"computer use 看一下 \[位置]"（如"computer use 看一下编辑器页面"），AI 会接管/观察对应界面。
- 涉及登录态、验证码等 AI 无法代做的步骤时，按提示手动接管。

## 三、防丢机制

- 协作者在 handoff.md「Active feedback」区自动记录未解决的反馈项（按时间倒序），你不用重复提醒。
- 反馈解决后会在 handoff「Recently shipped」留痕，可追溯。
