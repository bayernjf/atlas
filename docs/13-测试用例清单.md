| U14 | loop fail-safe | 恒真表达式：执行 maxIterations 轮后 exitReason=max_iterations 走 exitTarget（不触发 recursion_limit、仍 completed）；坏表达式/缺失变量：首轮即 exitReason=expression_error 退出且 expression_errors 非空 | 04 §5.3 fail-safe |
| U15 | loop 校验 | continueExpression 空/语法错、maxIterations 越界非整数、body/exit 缺失或相同或自环、出边数≠2 或直连 END、循环体无回边、循环体泄漏到 exitTarget、体内含 trigger/其他 loop（嵌套）、不经 loop 的非法环 | DSL 校验一次性聚合中文报错 | 04 §5.3 契约；U7 |

## 6. AI 评估用例（评估 Harness，原文 06 9.2）

### 6.1 evaluation_task 原文示例（refund_processing）

```yaml
evaluation_task:
  task_id: "refund_processing"
  description: "处理退款申请"
  test_cases:
    - input: {order_id: "12345", reason: "商品破损", amount: 299}
      expected: {action: "approve_refund", verify: "refund_status == 'completed'"}
    - input: {order_id: "12346", reason: "不想要了", amount: 5000}
      expected: {action: "request_human_approval", verify: "approval_request_created"}
  metrics: [task_success_rate, average_steps, decision_accuracy]
```

### 6.2 扩展评估用例（按 9.3 黄金测试集 ≥5 条要求补充）

| # | 输入 | 期望动作 | 验证 |
|---|---|---|---|
| A1 | 破损 299 | approve_refund | refund_status == completed |
| A2 | 不想要 5000 | request_human_approval | approval_request_created |
| A3 | 已发货商品退款 | 人工介入（涉及物流） | human_involved == true |
| A4 | 金额超阈值（如 10000） | request_human_approval | approval_request_created |
| A5 | 重复退款请求（幂等） | 拒绝或返回已处理 | duplicate_detected == true |
| A6 | 库存不足触发补货（Graph 分支） | urgent_replenish | replenish_created |

## 8. 测试执行建议

- Demo 阶段（W1-W10）：先建 U1-U10、I1-I8、E1-E7；回放测试（§4）与评估用例（§6）随编辑器与反思模块（Phase 2-3）落地。
- 每次迭代回归：至少跑黄金测试集（A1-A5）+ 沙盒 3 次成功。
- 覆盖率目标：单元层节点/变量/表达式 100% 核心路径，不做无意义全量覆盖率追逐。
