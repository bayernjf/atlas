## 4. 结构性缺口：上线形态不在任何门禁里

**PG 档才是生产形态，CI 却一次都没跑过它**〔跑+码〕：`.github/workflows/ci.yml` backend job 只有 `pip install` + `pytest`，**没有 postgres service**、不设 `ATLAS_RUN_INTEGRATION`（`:43` 注释明写默认 skip）；我实测 integration 标记 **44 / 1918（2.3%）**。本次手动 `ATLAS_RUN_INTEGRATION=1` 跑，即抓出一条既存红：`storage/pg.py:2063` `PgAuditStore.record()` 返回投影缺 `seq`，而 `tests/test_audit_log.py:31` 的 `_EVENT_KEYS` 要求它。

⇒ 后果说准：**M5b 以来所有「已 PG 化 / 跨重启可见」的承诺，目前没有任何自动化在守**。这几批的卖点恰恰是持久化，这是评审里最该被记住的一条。
