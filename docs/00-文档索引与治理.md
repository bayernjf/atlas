## 治理规则

1. **唯一事实源**：`docs/` 目录下 00-08 为规格文档的唯一事实源。原始两份文件（《产品与总体方案.md》《技术实现设计.md》）已于 2026-09-13 经机器核对（274 个章节标题全部映射、逐段覆盖率验证）后删除，其全部内容已并入本目录，源文档章节→文档映射见上方"原始文档映射"表。14-16 为治理类文档（缓做登记/环境分支/反馈工作流），与规格文档同受治理规则约束。
2. **改内容流程**：定位到对应文档 → 修改 → 若改动涉及新决策，在 08 任务迭代计划中记录 → 同步更新 03 契约索引。
3. **Schema 契约**：数据结构以 03 索引定位、以所在文档正文为唯一权威；改 Schema 必须同步所有引用该结构的位置（防漂移）。
4. **切分核对报告**（2026-09-12）：源文档全部章节已映射到目标文档；机器核对（段落级最长公共子串覆盖率）结论见交付说明，无信息丢失。
