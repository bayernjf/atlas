## 一、范围（MVP 切片）

**背景**：`SUPPORTED_NODE_TYPES` 现有 9 类（trigger/ai_decision/tool_call/condition/loop/parallel/wait/subgraph/human_approval），缺需求清单（编辑后台组件设计 §3.1 12 类）里的 **意图识别 / 信息抽取 / 内容生成**。三者与 `ai_decision` 同族（LLM 结构化输出），走既有 `llm/config.py` per-tenant 模型配置（第 5 个消费点）。

**本批取回**：
1. **三个节点类型**：`intent_recognition` / `info_extraction` / `content_generation` 进 `SUPPORTED_NODE_TYPES`（graph/dsl.py）+ 校验（config 形状、必填）
2. **LLM 执行**：新模块 `llm/structured.py` 三个客户端——`classify_intent(text, intents, examples)` → `{intent, confidence, slots}`；`extract_fields(text, fields)` → `{fields: {name: value}}`（照抽取字段 Schema）；`generate_content(context, template, style, max_length)` → `{text}`。全部走 `model_config` per-tenant（BYOK/内置两档复用，见 docs/93）；**无模型时显式 FAILED**（照 ai_decision prod 档 `AiDecisionUnavailable` 同款，不静默降级）
3. **loader 接线**：graph/loader.py 三节点执行分支（config → interpolate 上下文 → 客户端 → `{result, prompt_rendered}` 输出形状与 ai_decision 对齐）
4. **前端**：nodeCatalog.ts + i18n（zh/en 各 3 键）+ 属性面板——三节点 config 用 schema 声明走 forms 内核（ZW/ZX 基础：intents 数组、fields 数组、template/style 文本），画布节点渲染（icon/颜色分组）
5. **测试**：DSL 校验（非法 config 422）+ loader 执行（mock 客户端确定性断言）+ 前端目录/面板契约

**非目标（D61 不解除）**：意图多轮澄清、槽位训练、few-shot 自动学习、置信度阈值挂起转人工联动、NL 生成适配器配置、结构化输出深度契约（JSON Schema 严格校验，MVP 走 LLM 软输出+本地形状兜底）。

## 二、契约形状

### 2.1 节点 config

```
intent_recognition:
  intents: [{name: str(1-40), description: str(0-200), examples?: [str]} ]   # 必填 ≥1，≤20
  textSource: str   # 变量路径，缺省 trigger 上下文文本（照 ai_decision prompt 惯例）
  model?: str       # 节点级模型覆盖（照 ai_decision model 先例）
  输出: {intent: str|null, confidence: float, slots: {str:str}}

info_extraction:
  fields: [{name: str(1-40), type: enum[string,number,boolean,object], description: str(0-200)}]  # 必填 ≥1，≤30
  textSource: str
  model?: str
  输出: {fields: {name: value}, missing: [name]}

content_generation:
  template: str(1-2000)     # 必填，支持 {{}} 插值
  style?: str(0-200)        # 风格描述
  maxLength?: int(1-4000, 缺省 800)
  model?: str
  输出: {text: str, prompt_rendered: str}
```

### 2.2 执行语义

- 无模型（LITELLM 未配且无 BYOK）：三节点显式 `FAILED`（`AiDecisionUnavailable` 同款文案，demo_surface 不豁免——三节点无规则兜底，demo 档同 FAILED）
- LLM 返回非法形状：`{intent:null,...}` / `{fields:{}, missing:[...]}` 兜底（不 FAILED，记 llm_errors）
- 回放确定性：mock 回放（`mock_tools`）不桩三节点（与 ai_decision 同策略——回放漂移照既有口径，见打包 V）

### 2.3 前端

- nodeCatalog：三节点加入「AI 决策」分组，zh/en 名：意图识别/Intent Recognition、信息抽取/Info Extraction、内容生成/Content Generation
- 属性面板：intents/fields 数组编辑器（FormRenderer array 形态，ZX 基础）、template/style/maxLength 文本/数字控件
- i18n：node 命名空间 3 节点 × 3 键（name/desc/configLabel）
