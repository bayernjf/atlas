1. **Atlas 身份二选一**：继续做「AutoPilot/元层」主身份，还是承认当前就是「编排工作室」。

3. **A-01 是否第一优先，取决于 Atlas 用来干什么**：
   - 要替代手工网页操作 → A-01 第一；
   - 只做 API/DB 自动化 → A-05 先做，A-01 可后置。
4. **A2A 真实 run 之前先做 D48 租户绑定**：现在任何持 token 的调用方都能以任意 `tenant_id` 调用；plan-only 无害，扩到真实 run 就是跨租户读取面。
