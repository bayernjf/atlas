## 第六部分：运行时引擎设计
### 6.1 Loop 主循环实现
基于 LangGraph StateGraph 构建持久运行的状态机（代码示例）：
class LoopState(TypedDict):
goal: str
messages: list          # 对话/执行历史
current_node: str
observations: list      # 感知结果
variables: dict         # 会话变量
status: str             # running/paused/completed/error
memory_id: str
# 构建主循环
graph = StateGraph(LoopState)
graph.add_node("observe", observe_node)      # 调用Harness感知当前状态
graph.add_node("orient", orient_node)        # 分析数据，定位进展
graph.add_node("decide", decide_node)        # LLM决策下一步
graph.add_node("act", act_node)              # 执行工具/操作
graph.add_node("reflect", reflect_node)      # 阶段性反思
graph.add_edge("observe", "orient")
graph.add_conditional_edges("orient", should_continue)
graph.add_conditional_edges("decide", should_act_or_wait)
graph.add_conditional_edges("act", should_reflect_or_continue)
```

> **Graph condition 节点执行语义（Phase 2 首版，2026-09-14；契约权威见 04 §5.2）**：编辑后台 Graph 中的 condition 节点编译为 LangGraph conditional edges——同一 condition 节点的出边**全部**走 `add_conditional_edges`（不得与普通边混用，否则双路激活）。执行器按 config.branches 数组顺序短路求值（第一个为真者胜出），全假或求值异常时走 defaultTarget；求值只发生一次并写入 `outputs[condition_id]`，路由函数仅读取其中的 `target`。含变量的运行时类型错误/缺失变量 fail-safe 走 defaultTarget，错误进 `expression_errors`；trace（messages）追加一行 `condition-x: branch=<label|__default__> → target=<node_id>`。表达式首版白名单（比较/逻辑/括号/字面量/`{{路径}}`，无算术与函数、禁止 eval）见 04 §5.1。
### 6.2 决策节点实现（代码示例）
def decide_node(state: LoopState):
# 1. 从记忆中检索相关上下文
relevant_memory = memory_retriever.query(state.goal, state.messages[-5:])
# 2. 构建提示词（含思考缓冲区）
prompt = f"""
【目标】{state.goal}
【当前状态】{state.messages[-10:]}
【相关记忆】{relevant_memory}

请先进行内部推理（思考：
1. 当前进展如何？
2. 下一步应该做什么？
3. 有什么风险？
然后输出结构化决策。
# 3. 调用LLM，强制结构化输出
decision = llm.with_structured_output(DecisionSchema).invoke(prompt)

# 4. 置信度检查
if decision.confidence < 0.6:
return {"status": "paused", "request_human": True, ...}

return {"current_node": decision.next_action, ...}

type HarnessAdapter interface {
ListCapabilities(ctx context.Context) ([]Capability, error)

### 6.5 Web 操作适配器（Demo 核心）
三层定位冗余：（代码示例）
class WebHarnessAdapter:
def click(self, element_desc: str, selector: str = None):
# 第一层：精确选择器
if selector:
try:
self.page.click(selector, timeout=3000)
return success()
except:
pass

# 第二层：视觉语义定位
screenshot = self.page.screenshot()
elements = omni_parser.parse(screenshot)  # 返回元素列表+描述
target = llm_match(element_desc, elements)
if target.confidence > 0.7:
self.page.mouse.click(target.x, target.y)
self.update_selector_cache(element_desc, target.selector)
return success()

# 第三层：LLM全图推理
result = vision_llm.analyze(screenshot, f"找到{element_desc}并返回坐标")
if result.coordinates:
self.page.mouse.click(*result.coordinates)
return success()

return failed("元素未找到，三层定位均失败")
