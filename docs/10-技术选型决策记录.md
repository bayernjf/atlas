## 2. Demo 阶段（W1-W10）技术栈锁定

依据：08 7.2 Demo 技术栈实现 + 06 代码示例。Demo 阶段只实现以下子集：

```
/backend
/engine
loop.py          # OODA主循环（LangGraph StateGraph，见 06 6.1）
graph_loader.py  # DSL→LangGraph（见 02 Graph DSL）
memory.py        # 基础记忆（Redis + PostgreSQL + pgvector，见 06 6.3）
/harness
base.py          # 适配器基类（见 06 6.4 接口）
web_harness.py   # Playwright适配器（三层定位，见 06 6.5）
gateway.py       # 工具注册和路由（见 04 适配器注册）
/api
main.py          # FastAPI入口
/frontend
/src
/components/canvas        # React Flow画布
/components/nodePanel     # 节点面板
/components/propertyPanel # 属性面板
/components/debugConsole  # 调试控制台
/pages/Editor.jsx
/pages/Dashboard.jsx
/store/editorStore.js     # Zustand状态
```

**Demo 依赖清单（可直接进 pyproject.toml）**：`langgraph`、`langchain`、`litellm`、`playwright`、`fastapi`、`uvicorn`、`psycopg`/`sqlalchemy`、`pgvector`、`redis`、`pydantic`、`pytest`；前端：`react`、`react-flow-renderer`、`zustand`、`antd`。
> 注：以上依赖名为通用库名，具体版本号待环境搭建时以 PyPI/npm 最新稳定版为准（决策记录不锁死版本，由 AI 落码时解析）。
