```
/pages/Editor.tsx
/pages/Dashboard.tsx
/store/editorStore.ts     # Zustand状态
```

**Demo 依赖清单（可直接进 pyproject.toml）**：`langgraph`、`langchain`、`litellm`、`playwright`、`fastapi`、`uvicorn`、`psycopg`/`sqlalchemy`、`pgvector`、`redis`、`pydantic`、`pytest`；前端（2026-09-13 落码解析）：`react@19` / `react-dom@19`（满足 React 18+）、`@xyflow/react@12`（React Flow 现行包名，替代已弃用的 `react-flow-renderer`）、`zustand@5`、`antd@6`，构建链 Vite 8 + TypeScript 6 + pnpm，前端单测 vitest 5（T6，见 §4）。
