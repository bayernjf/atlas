七、建议开发路线图
- Phase 1: 最小可行引擎（2个月）
选择1个平台（如企业内部OA），实现：固定操作Graph + 基础Harness（浏览器、API）+ 单步决策Loop。证明可以按照图完成一条审批流程。
- Phase 2: 动态反馈与DIY（3个月）
加入异常处理Loop、反思模块、可视化Graph编辑器。让非技术人员能通过自然语言定义一个新流程，引擎自动执行。
- Phase 3: 平台化适配（3个月）
开放Harness适配器开发规范，实现界面操作适配器的自愈能力，接入2-3种差异巨大的场景（如电商+物联网），验证通用性。
- Phase 4: 智能体市场与进化（持续）
用户可发布自己训练的运营体，新用户一键导入即可适配类似产品。形成运营策略的飞轮。

> **Phase 2 第二项落码（2026-09-14）**：循环节点（loop）端到端落地，v1 仅条件循环（while）。契约写入 04 §5.3（config `mode/continueExpression/maxIterations/bodyTarget/exitTarget`；EdgeDSL 与 Graph version 仍不变）。两项用户拍板决策：① v1 只做 while，复用 condition 表达式白名单，循环变量只暴露 `index`（遍历循环/数组逐项/item/结果聚合缓做 D16，break/continue 缓做 D17）；② 达最大次数 fail-safe 退出（正常路由 exitTarget、`exitReason=max_iterations`、运行仍 completed），表达式运行时异常同样 fail-safe（`expression_error`）。U7 调和：loop 循环体回边是唯一合法环，DSL 临时移除白名单回边后对余图 DFS 环检测；循环体 BFS 界定，泄漏退出目标/体内嵌套 loop 或 trigger/无回边/游离体分支均聚合中文报错；不支持嵌套循环。loader 可重入执行器（重访覆盖 outputs[loop_id]、首轮播种自身 index）、出边全 conditional、recursion_limit 按循环体规模派生。前端属性面板/双 Handle/循环体·退出边标签/删除清理/运行 trace 中文化齐备；NL 生成 prompt 枚举补 loop。
