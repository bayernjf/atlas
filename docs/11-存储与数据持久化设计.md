# Atlas 存储与数据持久化设计

> **来源**：06 运行时"6.3 记忆系统"存储层次 + 02 技术选型（PostgreSQL/pgvector/Redis）+ 03 Schema 契约 + 05 memory_config 完整字段。本文为**存储设计**：各数据对象的持久化归属、表结构建议、读写路径。
> **AI 使用提示**：落库代码、ORM 模型、迁移脚本以此为准。标注"原文依据"的行为文档已定，标注"建议"的为本文推导、可按实现调整。

## 1. 存储分层总览（原文依据：06 6.3）

| 数据类别 | 存储介质 | 内容 | 更新策略 |
|---|---|---|---|
| 短期工作记忆 | Redis / LangGraph Checkpointer | 最近 N 步对话/操作 | 实时写入 |
| 中期摘要记忆 | PostgreSQL | 每超阈值自动摘要 | 步数/Token 阈值触发 |
| 长期事实记忆 | pgvector | 业务事实、用户偏好 | 会话结束提取 |
| 案例记忆 | 结构化索引（PostgreSQL 表） | 成功/失败轨迹 | 定期批量写入 |
| 运行状态 | LangGraph Checkpointer | Loop 状态（LoopState） | 每步持久化 |
| 配置/业务数据 | PostgreSQL | Graph 定义、节点、工具、运营体镜像 | 编辑保存时写入 |
| 日志/审计 | 不可篡改日志（06 安全清单） | 全链路操作审计 | 实时追加 |
| 缓存 | Redis | 会话缓存、工具结果缓存 | TTL 过期 |

## 3. 存储读写路径（原文依据：06 6.1-6.3）

```
Loop 每步:
  observe → 结果写入短期工作记忆（Redis 实时）
  decide  → 从记忆检索相关上下文（memory_retriever.query，见 06 6.2）
           → 短期超阈值 → 触发摘要写入 PostgreSQL（中期）
           → 会话结束 → 提取事实写入 pgvector（长期）
  执行完成 → 案例轨迹批量写入案例表（定期）
  LoopState 每步 → Checkpointer 持久化（可恢复）
```

## 4. 数据保留与隐私（原文依据：05 2.3 privacy + 06 安全清单）

- `retention_max_days` 控制最大保留天数；`user_deletion_support` 支持用户删除记忆（删除需级联清理 Redis/pgvector/PostgreSQL）。
- PII 脱敏：日志自动模糊（Presidio），记忆写入前按 `pii_redaction` 过滤。
- 审计追踪：不可篡改日志，全链路追踪（06 安全设计清单）。
