# 打包 W 契约：随机/UUID 表达式函数与回放种子化（D15 余部切片）

> 形状权威＝本文。落码与本文冲突时先改本文再改代码；只许增测，不改既有契约语义。
> 范围一句话：条件表达式新增 `random()`/`randint(a,b)`/`uuid()` 三个白名单函数，
> **随机性来自每次运行注入的种子 RNG**；seed 是与 recorded_at 同类的录制事实，
> 随 RunResult 回传、随录制用例冻结，回放单用例与发布门禁**按录制种子确定重放**。
> 不做 `choice()`/采样、不做客户端钉种子、不做断点续跑帧携种子。

## 1. 决策（四条；改任何一条先改本文）

- **D-1 新增三个白名单函数（graph/conditions.py，前端 conditions.ts 同构）**：
  - `random()`（0 参，number）→ `[0.0, 1.0)` 浮点，取注入 RNG 的 `.random()`；
  - `randint(a, b)`（2 参，number）→ 闭区间整数；a/b 必须是**非布尔整数**，且 `a <= b`，
    否则中文报错 `函数 "randint" 的参数必须是整数`（COND_TYPE_MISMATCH）/
    `函数 "randint" 下界不能大于上界`（COND_INVALID_RANGE）；
  - `uuid()`（0 参，string）→ version-4 UUID 规范字符串（带连字符），
    字节全部取自注入 RNG（`uuid.UUID(bytes=rng.getrandbits(128).to_bytes(16,"big"), version=4)`），
    **绝不读 os.urandom/uuid4 默认源**。
  三名加入 `_NONDETERMINISTIC`（静态折叠不执行）；返回类型按 `_FUNCTIONS` 推断。
- **D-2 种子 RNG 注入与时钟同构**：`evaluate_expression` 加 kw-only `rng: random.Random | None = None`，
  `_evaluate`/`_evaluate_function` 透传；未传 rng 时（监控告警/既有直接调用）按调用新建
  `random.Random()`（系统熵），与旧行为等价。`run_graph` 加公开参数 `rng_seed: int | None = None`
  ——None 时入口以 `secrets.randbits(63)` 生成；每次运行一个 `random.Random(rng_seed)`，
  经 `compile_graph(expr_rng=...)` 注入，loader 三求值点传 `rng=expr_rng`；
  subgraph 重入经内部参数 `_expr_rng` **复用同一实例**（单次运行同一条随机流，节点序确定）。
- **D-3 seed 是录制事实，回放与门禁按种子锚定**：
  - RunResult 与 run_end 帧纯超集加 `rng_seed: int`（run_graph 写入 result，
    `_finish` 的 run_end 同步携带；RunGraphResponse 补可选字段）；
  - `RecordingCreateRequest`/`RecordingCase` 纯超集加 `rng_seed: int | None = None`，
    `RecordingStore.add(..., rng_seed=None)`；前端 saveRecording 原样回带所录运行的 seed；
  - replay.py 增 `seed_anchor(case) -> (int | None, str | None)`：取 case.rng_seed，
    缺失（历史用例）→ (None, "用例缺少 rng_seed，回放使用新随机种子（random/randint/uuid 分支可能漂移）")；
  - replay 端点（mock 与非 mock 两条路径一致）与 gate 把 seed 传给 `run_graph(rng_seed=...)`，
    报告在有 note 时挂 `rng_seed_note`（与 clock_note 同口径），异常折叠报告不带。
- **D-4 migration 033（PG recordings 补 rng_seed 列）／零新依赖／无新 ADR**；前端仅函数表同构＋录制透传 seed，不新增页面交互；
  不解除 D15（`choice()`/数组采样、客户端钉种子、断点续跑帧携种子、named timezone 仍缓做）。

## 4. 测试与验收（U970 起；落常跑，不依赖网络）

- **U970** 条件函数纯逻辑：固定 `rng=random.Random(7)`，random()/randint()/uuid() 取值与
  直接调用标准库同序一致；同一种子两次求值相等；uuid 为合法 v4 字符串；
  randint 非整数/bool/a>b 各自中文报错；arity 错误；三函数不被常量折叠。
- **U971** run_graph 种子：同 rng_seed 两次运行（含随机分支条件）outputs 完全一致；
  不传 seed 时两次运行结果不同且 result.rng_seed 非空；不同 seed 可产生不同分支。
- **U972** subgraph 共享随机流：含随机函数的 subgraph，同 seed 重放一致（经 _expr_rng 复用）。
- **U973** 录制回放种子锚定：经真实运行录制（带 rng_seed 入库），非 mock replay matches=true；
  gate 通过；手工构造 rng_seed=None 的历史用例 → replay matches 可能漂移且报告挂 rng_seed_note；
  mock replay 同样按种子重放；不出现 mocked_conditions 干扰。
- 复跑：既有 conditions / clock / recording / release gate 全套零改动语义；
  `tests/test_handoff_integrity.py` 绿。

## 6. 残余风险（别当成「D15 收干净了」）

- 历史用例无 rng_seed：含随机函数分支的旧用例回放仍可能漂移（报告明示 rng_seed_note）；
  要消除只能重新录制，不做静默补种子（那等于伪造录制事实）。
- 断点续跑（resume 帧）不携种子：挂起后续跑使用新随机流——录制回放不走 resume 路径，
  真实挂起场景若随机分支位于挂起点之后可能不可复现，帧携种子随后续批。
- 种子锚定验的是「同一随机抽样在当前图上是否导出同一路径/产出」，不验「今天重新抽样会怎样」
  （与打包 V 脚本分支同构的语义边界）。
- `choice()`/按权重采样、客户端钉种子做 property-based 重放、named timezone 仍缓做（D15），触发条件不变。
