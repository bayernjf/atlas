## 1. 基线实测（为什么这不算"已经做了"）

〔码〕逐条对当前 HEAD 实核，不是引旧文档：

1. **反思候选只到「呈现＋人工采纳」**：`run_pass`（`reflection/candidate.py:281`）产候选/报告，`PUT /api/reflection/candidates/{id}/decision`（`main.py:1972`）只登记 adopted/dismissed 标记（`record_decision`）——**不改图、不发布、不动路由**（守 T22，`candidate.py:3-5` 明文"只出建议，不动系统"）。前端 `Reflection.tsx` 的"采纳"是跳转编辑器让人手动改图（docs/92/94 引导），没有一条代码路径把候选自动落进图。
2. **候选的变更形状已收敛**：白名单恰 4 条（`reflection/tunables.py:46`）：`approval_limit`（graph_variable，落 `graph.variables`，值字符串如 "500"）、`node.confidenceThreshold`（node_config，落 `nodes[].config`，带 `node_id` 确定性定位，docs/94 E-3）、`monitor.failure_rate.rate`（monitor_rule，落监控 `RuleConfig.failure_rate.rate`）、`gate.run_error_rate`（gate_config，落 `RolloutConfig.gate.metrics[].threshold`）。fail-closed 校验（`validate_changes`：白名单外/越界整份作废）。
3. **灰度状态机与门控齐备，但起点全手动**：`RoutingStore`（`routing/store.py:63`）idle→canary→full→rolled_back；`start` 取最新两发布版；`promote` 仅手动（`store.py:111` 注释明文"唯一放量路径，仅手动，代码中不存在任何自动 promote"）；门控 `evaluate_after_run`（`routing/gate.py:71`）canary 期越阈自动回滚（actor="auto"）+告警——**自动回滚已有，自动进灰度没有**。
4. **黄金回放门禁齐备，但只被人工调用**：`run_release_gate`（`recording/gate.py:111`）对 latest 草稿逐例重跑录制用例；`POST /api/graphs/{id}/release-gate`（manual，`main.py:3197`）；`POST /api/graphs/{id}` publish 带 `{"gate": true}` blocked→409（`main.py:3573`）。没有"候选自动触发门禁并据此推进"的链。
5. **影子运行齐备，同样只能人工调用**：`POST /api/graphs/{id}/shadow-runs`（`main.py:3311`）旁路跑完整决策链（预置审批、写短路、不进生产观测面）。BP 的"必跑影子"复用同一逻辑，不新造。
6. **发布齐备**：`publish_graph`（`main.py:3573`）冻结 latest 草稿＋派生调度（`_derive_schedule_on_publish`）；`versioning/publish.py` 递归钉版 subgraph。
7. **反思触发两条路径（调度 reflect 动作 `main.py:1616`、`schedule.run_now` `main.py:1905`），均止于产候选**——没有"候选 → 自动生效"的后半程。
8. **可自动生效的最小安全边界**：4 条白名单里 `approval_limit` 与 `node.confidenceThreshold` 落在**图草稿内**（patch 后可直接被影子/门禁/发布覆盖验证）；`monitor.failure_rate.rate` 落在监控规则（`monitoring/records.py` `get_rules/update_rules`）、`gate.run_error_rate` 落在 `RolloutConfig.gate.metrics`（routing 配置）——**两者不在图草稿闭环内**，自动 apply 会越过"草稿→门禁→发布"的验证链，且改防御面（监控灵敏度/回滚灵敏度）有自指风险，v1 不自动。

## 2. 决策（落码不得偏离；改任何一条先改本文）

- **BP-D1（E-P1 拍板）自动生效类别＝按 scope 分开关，v1 只开图内参数类**：
  - 类别开关按 `TunableScope` 维度（`graph_variable` / `node_config` / `monitor_rule` / `gate_config`），**缺省全关（fail-closed：未显式开启的类别一律不自动）**；
  - v1 允许自动的类别＝**`graph_variable`＋`node_config`**（图内参数，patch 后过影子＋黄金回放＋发布验证链）；
  - **`monitor_rule`＋`gate_config` 本批不自动**（apply 目标不在图草稿闭环内、影响防御面；开关保留，将来另行拍板）；
  - **结构类（增删节点／改边／promptTemplate）恒不自动**：promptTemplate 是无界文本、不在白名单（docs/88 D-4 特别条款）；候选 v1 不产结构类变更，未来白名单增加结构 key 需另行拍板。
- **BP-D2 自动生效入口＝候选上的动作端点** `POST /api/reflection/candidates/{id}/autoapply`（不新增"每 pass 自动跑"的常驻链——最小切片，人点/调度触发，可控）。幂等：同一候选只跑一次自动生效（重复 409）。
- **BP-D3 patch 形状＝`PatchPlan`**：`patch_candidate(changes, latest_draft, base_version, graph_snapshot)` → `(new_draft, diff)`，只认 graph_variable/node_config 两类；diff 描述逐条 `{param_key, from, to, node_id, path}`（可审计）。apply 前校验**「latest 草稿与 base_version 发布快照一致」**（内容比较，排除 `releaseVersion`；快照缺失＝无法确认基线 → fail-closed 中止）：草稿被人工改过（dirty）→ 中止并记录原因（**不自动覆盖人工改动**）。
- **BP-D4 自动推进链（一鼓作气，每步留证据）**：patch → **影子必跑**（复用 shadow 逻辑：空 inputs＋预置审批，健康检查语义）→ **黄金回放**（复用 `run_release_gate`；blocked → 中止留证据）→ **patch 落地**（把 `new_draft` 写回 latest 草稿，否则 publish 发布的是旧草稿；仅 shadow/gate 均通过后写回，失败路径不触碰草稿）→ **自动 publish**（gate=true；blocked→409 中止）→ **自动 start canary**（版本不足 2 时记录"已发布未进灰度"，留证据不报错）→ **指标门控自动回滚**（复用 `routing/gate.py`，已有）。
- **BP-D5 人可随时中止**：`POST /api/reflection/autoapply/{run_id}/abort`——pending/published 态直接中止不再推进；canary 态中止＝手动 rollback（actor="manual"，复用 `RoutingStore.rollback`）；幂等（已终态重复 abort 返现状）。
- **BP-D6 每圈证据＝`AutoApplyRun` 记录**：内存 ring 100/租户（照 ReflectionStore 先例）＋ PG 表 `autoapply_runs`（迁移 053，跨重启可见）。字段：`run_id`（`aa-N`）、candidate_id、graph_id、base_version、enabled_scopes、patch（含 diff）、shadow 结果、gate 报告摘要、publish_version、rollout 状态、abort/rollback 记录、各阶段时间戳与结果。**"自动"的每一步都留下可否证记录**（docs/127 里程碑 E Done-when）。
- **BP-D7 复用与纪律**：影子/门禁/发布/灰度全复用既有件；**零新依赖、零新错误码、无 ADR**；不自动 promote（现状不变）；单副本约束（docs/62）继续有效；D77 判胜口径半边＝autoapply 记录沉淀每圈 candidate vs stable 指标对照（判胜逻辑留 D77 实验面）。

## 3. 契约形状

### 3.1 `reflection/patch.py`（新增，纯新增）

```
def patch_candidate(*, changes: list[Change], latest_draft: dict | None,
                    base_version: int, graph_snapshot: dict | None)
    -> PatchOutcome   # {ok: bool, new_draft?: dict, diff?: list[PatchDiff], reason?: str}
```

- 只处理 `scope ∈ {graph_variable, node_config}` 的 change（其余 scope 的行跳过并计入 diff 的 `skipped`，**不静默吞**）；
- `latest_draft is None`（无草稿）→ `ok=False, reason="无 latest 草稿"`；`graph_snapshot is None`（base_version 无对应发布）或 `latest 草稿 ≠ 发布快照`（内容比较，排除 `releaseVersion`；dirty）→ `ok=False, reason="草稿与候选基线不一致，需人工处理"`（不自动覆盖）；
- `graph_variable`：改 `graph.variables[].value`（命中 name；未命中 → `ok=False`，照实不猜）；
- `node_config`：改 `nodes[].config.confidenceThreshold`（按 `node_id` 定位；node_id 缺失/指向非 ai_decision 节点 → `ok=False`，照实不猜）；
- diff 条目：`{param_key, from, to, node_id|null, path, skipped: bool, reason?: str}`。

### 3.2 `reflection/autoapply.py`（新增，编排）

```
class AutoApplyStore:            # 内存 ring 100/租户（照 ReflectionStore 先例）+ PgAutoApplyStore（迁移 053）
    next_run_id / add / get / list / update_status / record_stage

def run_autoapply(services, *, tenant_id, candidate_id, enabled_scopes: set[str]) -> AutoApplyRun
def abort_autoapply(services, *, tenant_id, run_id) -> AutoApplyRun
```

`run_autoapply` 推进链（每阶段 `record_stage` 落证据，任一失败中止并留原因）：

1. 候选存在且 `decision_status != "adopted"` 前置检查（**dismissed/已处理候选不自动**）；候选 changes 的 scope ⊆ enabled_scopes 才继续（越类别 → 中止留证据）；
2. `patch_candidate` → dirty/形状异常 → 中止；
3. **影子必跑**：对 `new_draft` 跑一次 shadow（复用 shadow 逻辑：空 inputs、预置全部审批与 wait 秒过、独立 broker/tracer、写短路）；异常 → 中止；
4. **黄金回放**：`run_release_gate(new_draft, cases=recording_store.list(), ...)`；`blocked` → 中止（带 GateReport 摘要）；`total=0`（skipped）**不阻塞**（照现有发布语义）；
5. **patch 落地**：`graph_store.update_draft(graph_id, new_draft)`（写回 latest 草稿——仅 shadow/gate 均通过后；写回失败 → 中止留证，失败路径不触碰草稿）；
6. **自动 publish**：`publish_graph`（gate=true 语义，blocked→409 中止）；记录 `publish_version`；
7. **自动 start canary**：`routing_store.start(graph_id, versions)`；版本 <2 → 记录"已发布未进灰度（版本不足）"终态留证据，不报错；成功 → 记录 `rollout_status=canary`；
8. 终态 `completed`；门控越阈自动回滚走既有 `evaluate_after_run`（routing/gate.py，本批零改动），autoapply 记录通过 rollout snapshot 关联回滚结果。

### 3.3 迁移 053（`autoapply_runs` 表）

```sql
CREATE TABLE IF NOT EXISTS autoapply_runs (
    tenant_id TEXT NOT NULL,
    run_id TEXT NOT NULL,               -- 'aa-N'，N 取 storage_id_seq
    candidate_id TEXT NOT NULL,
    graph_id TEXT NOT NULL,
    base_version INTEGER NOT NULL,
    enabled_scopes JSONB NOT NULL,      -- 启动时生效的类别开关快照
    patch JSONB,                        -- PatchPlan（diff 全量，含 skipped）
    shadow JSONB,                       -- 影子结果摘要
    gate JSONB,                         -- GateReport 摘要
    publish_version INTEGER,
    rollout_status TEXT,
    status TEXT NOT NULL,               -- pending/completed/aborted/failed
    reason TEXT,
    stages JSONB NOT NULL DEFAULT '[]', -- 每阶段 {stage, at, ok, note}
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    PRIMARY KEY (tenant_id, run_id)
);
```

### 3.4 REST（新端点，零新错误码）

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `POST /api/reflection/candidates/{candidate_id}/autoapply` | operate | 启动候选自动生效（BP-D2）；body `{enabledScopes: [str]}` 缺省=该租户当前开启的类别（`GET /api/reflection/autoapply/config` 可查）；候选不存在 404、已跑过 409、dismissed/已 adopted 409；返 `AutoApplyRun` |

## 5. 验收（Done-when 逐条，docs/127 §5）

1. **候选 → 必跑影子＋黄金回放**：自动生效链启动后，影子与 release-gate 都跑且留证据（gate blocked 中止、total=0 不阻塞）；
2. **自动进灰度**：publish 后自动 start canary（版本不足记录留证）；
3. **指标劣化即回滚**：canary 期越阈走既有 `evaluate_after_run` 自动回滚（actor="auto"）——复用验证，不新写；
4. **人可随时中止并看到每一圈的证据**：abort 端点幂等生效；`GET /api/reflection/autoapply/{run_id}` 返回全阶段可否证记录；
5. **"自动"每一步留下可否证记录**：stages 数组含每阶段时间戳/结果；patch 含 diff 全量。

反向门（植缺陷转红）：

- 类别开关未开 → autoapply 拒绝/跳过并留证（fail-closed）；
- 结构类/promptTemplate 恒不自动（不进入任何自动路径）；
- dirty 草稿（base_version ≠ latest）→ 中止不覆盖人工改动；
- gate blocked → 中止不发布；
- 同一候选重复 autoapply → 409；
- dismissed/adopted 候选 → 409；
- monitor_rule/gate_config 类别 → 即便出现在候选里也不自动（v1 不落图内 patch）。

用例预留：**U1455–U1470**（编号续 BO 的 U1454；详见 docs/13 §X 本批节）。

## 6. 风险与边界

- **自动生效是 opt-in**：开关缺省全关；类别只开图内参数类；每条链都有影子/门禁/门控三层保险；
- **不自动 promote**：灰度到 canary 为止，全量仍人工（唯一放量路径现状不变）；
- **影子语义**：空 inputs＋预置审批＝健康检查；业务形态验证以黄金回放（录制用例）为准；
- **monitor/gate 类别不自动**：改防御面风险自指，留人工；
- **dirty 草稿保护**：自动不覆盖人工改动（中止留证）；
- 单副本约束（docs/62）继续有效；L3 离线训练 D2 不解除。
