## 1. 基线实核（2026-10-15，只读）

### 1.1 审批 HMAC 短链已成熟，可直接复用同形（D76 的"不新建鉴权形态"）

- `src/atlas/collaboration/email_token.py`：`EmailToken`＝`base64url(json).base64url(HMAC-SHA256)`，密钥链 `ATLAS_APPROVAL_HMAC_SECRET` → `ATLAS_MASTER_KEY` → dev 固定密钥（prod 缺密钥 raise）；短时效（MAX_TTL_SECONDS=3600＋EXPIRY_GRACE_SECONDS=300）；端点层统一 404 不区分原因（`TokenMalformed/BadSignature/Expired` 子类细分）。
- 先例：`email-view`/`email-decision` 两个**公开端点**（无 principal）验签后提供只读视图/提交决策（`main.py:6202`、`6078` 注释明说"邮件深链端点无 principal，不走本校验"）。
- **结论**：嵌入短链＝同一签名算法/同一密钥来源/同一失效处理，载荷换为 `{tenant_id, graph_id, exp}`——不是新建鉴权形态，是同形第二消费方（与 email token 并列，非替代）。

### 1.2 网页嵌入在 docs/05 有位置、无实现

- `docs/05 §4.2` 部署方式全景：网页嵌入＝「用户点击/页面事件，网页浮层/侧边栏，产品操作指引」；§4.3 `deployment_config` 已有 `interaction_channels[].type=web_widget` 槽位。
- `docs/14 D76`（⬜ 未启动）：一期只做一种＝**网页嵌入**；IM 嵌入依赖 D24/D73、SDK 依赖 D22 产物形态、私有化/边缘不进。
- 前端无 Embed 页；既有公开页先例＝`EmailApproval.tsx`（邮件决策落地页，无登录态）。
- **结论**：嵌入配置＝docs/05 §4.3 部署配置的 web_widget 具体化，落为第七类 SchemaRegistry 实体（F-P1 拍板，见 §3.1）。

### 1.3 造工具的三条既有半成品链（D71 的复用面）

- **契约**：`harness/base.py` 有 `Capability`（name/description/action/input_schema/output_schema/permission/timeout/is_idempotent，构造期按白名单校验 schema 形状）；**代码里零 `AdapterDefinition` 类型**（grep 全仓无命中）——docs/05 与 D71 登记说的"契约已在 docs/05 与 harness/base"实为概念级，落码要新增类型。
- **导入先例**：`openapi/` 全链成熟——`POST /api/openapi/imports`（落 `openapi_imports` store，进程内＋PG 两档）、`openapi/adapter.py` `ImportedApiHarnessAdapter`（adapter_id=`openapi:{spec_id}`，从 operation 描述符生成 Capability，执行走 `HttpApiClient` 出向过 `EgressGuard`）；**运行面装配**＝`harness/runtime.py:100-145` 每次 `_runtime_registry` 从 store `list()` 动态重建并 `register`（编译/运行按需，非静态注册）。
- **结构化输出**：`llm/structured.py` 有通用 `call_structured_json`（打包 AB 的范式）＋`classify_intent/extract_fields/generate_content/extract_memories` 具体客户端；`/api/nl/generate` 已挂 `usage_context`（打包 AU 的记账通道）。
- **采纳形态**：D51＝reflection candidate 的 `PUT .../decision`（adopted/dismissed、operate、可改判、审计），`Change.node_id`＋`resolve_node_ids` 确定性补全。
- **dry-run 先例**：无独立"连通校验"端点；`ImportedApiHarnessAdapter` 执行期真实发请求（HttpApiClient，传输层失败 → FAILED），`httpapi/` 有 `DEFAULT_TIMEOUT`/`HttpApiCallError`。dry-run 校验须自建（只读探测，不落运行账）。

### 1.4 零命中与边界（照实记）

- `AdapterDefinition` 在 `src/atlas/` 与 `tests/` **零命中**（本批新增类型的依据）。
- 造工具**不是**「AI 改 Atlas 自身代码」（Meta Layer 远期，docs/126 §6 明确不进）——本批只造**外挂平台适配器**。
- 嵌入面一期只读（看状态/参数），**不做**运营操作（写/决策走既有端点半点不新开）。

## 2. 形状与范围

### 2.1 D76 网页嵌入（一期最小）

- **嵌入配置实体** `embed_configs`（第七类 SchemaRegistry 实体）：租户级一条＝`{tenant_id, graph_id, enabled, token_ttl_seconds}`（PK tenant_id+graph_id）；graph 维度的"允许只读嵌入"开关，缺省全关（fail-closed）。
- **短链生成**：`POST /api/embeds`（admin/operate）→ 签 `{tenant_id, graph_id, exp}` 返 `https://…/embed/{token}`（同形 HMAC，密钥链同上；token_ttl_seconds 配置化，上限 86400）。
- **公开只读面**：`GET /api/embeds/{token}`（无 principal，验签失败统一 404）→ 只读投影＝graph 元信息（name/version/节点数/参数白名单值）＋最近运行摘要（completed/failed、时间、耗时；复用 monitoring 运行记录，不含密钥/决策）。前端 `Embed.tsx` 只读页（无登录态，参考 EmailApproval.tsx）。
- **配置表单**：`GET/PUT /api/embeds/config`（admin）——嵌入配置入 forms 内核（第七实体，走 `saved-graph-select` 既有业务控件）；03 索引加 `embed_config` 行。

### 2.2 D71 NL 造工具（最小切片）

- **类型**：新增 `harness/definition.py` `AdapterDefinition`：`{name, description, base_url, auth_type("none"|"header"|"query"), capabilities[]（Capability 同构：name/description/input_schema/output_schema/permission/is_idempotent）}`；构造期按 `Capability.__post_init__` 同一白名单校验 schema 形状。
- **NL 草稿**：`llm/structured.py` 新增 `generate_adapter_definition(prompt, tenant_id)`（走 `call_structured_json`，失败显式 `LLMStructuredUnavailable`，不静默降级——照打包 AB 纪律）；`POST /api/adapter-drafts`（operate）＝prompt → 草稿落 `adapter_drafts` store。
- **dry-run 连通校验**：`POST /api/adapter-drafts/{id}/dry-run`（operate）→ `HttpApiClient` 对 `base_url` 发只读 GET（出向过 `EgressGuard`；无凭据/非 2xx/传输失败 → `reachable=false`＋原因，不落运行账）。
- **人采纳**：`PUT /api/adapter-drafts/{id}/decision`（admin；adopted/dismissed、可改判、审计——复用 D51 形态）；**F-P2**：草稿 `permission` 默认 READ（auth_type 非 none 时须 admin 显式开）、**adopt 动作本身即人审**（admin 才能 decision），采纳后 `granted_permissions=最小集`。
- **运行时装配**：adopted 草稿 → 新 `harness/generated.py` `GeneratedApiHarnessAdapter`（adapter_id=`generated:{draft_id}`，capabilities 描述符执行走 `HttpApiClient`，与 `ImportedApiHarnessAdapter` 同构）；`runtime.py` 装配循环追加 `services.adapter_drafts.list(adopted=True)` → register。
- **存储**：`adapter_drafts` 两档（进程内＋PG 迁移 055）——采纳是配置资产，跨重启不可丢（同 D51 理由）。

## 3. 决策

### 3.1 F-P1 拍板＝嵌入配置作为 SchemaRegistry 第七类实体（**是**）

- 理由：嵌入配置是**真实运营者配置面**（哪个图可被嵌入、token 时效、开关），与 node/tool/card/deploy 同形态接 forms（`saved-graph-select` 控件已有）；docs/115 §8 的 YAGNI 结论针对"抽统一 SourceRegistry 无消费者"，单实体接入 forms 是既有五先例（node/tool/card/deploy/template），不是抽框架。
- 03 索引加 `embed_config` 行（docs/05 §4.3 web_widget 具体化）；docs/14 D76 行翻 🟡。

### 3.2 F-P2 拍板＝造的适配器默认最小权限＋采纳即人审（按 docs/127 建议）

- 草稿 `permission` 缺省 READ；`auth_type` 非 none 需 admin 显式确认（照实记录：v1 的"首次运行强制人审"落地为 **adopt 动作＝admin 人审＋granted READ 最小集**，真实执行不再插人工环节——与既有工具调用无人工环节的现状一致，不新增运行期人审形态）。

### 3.3 其余决策

- **BQ-D1** 嵌入 token 复用审批 HMAC 同形（同一算法/密钥链/失效处理），载荷换 `{tenant_id, graph_id, exp}`；验签失败统一 404。
- **BQ-D2** 嵌入面只读：仅图元信息＋最近运行摘要（monitoring 已有），不含密钥/决策/草稿；不做运营操作。
- **BQ-D3** dry-run 只读探测：GET base_url、过 EgressGuard、不落运行账；失败标记 `reachable=false`＋原因（照实不猜）。
- **BQ-D4** 草稿采纳持久化：`adapter_drafts` 两档（迁移 055）；dismissed/adopted 可改判（D51 形态）；adopted 后 runtime 动态装配。
- **BQ-D5** NL 造工具走既有 `call_structured_json`（打包 AB 范式），失败显式错误不静默；`/api/nl/generate` 的 `usage_context` 记账纪律延伸到新端点。
- **BQ-D6** 零新依赖／零新错误码／无 ADR；前端零新控件（复用 saved-graph-select）；`EgressGuard` 复用既有出向策略。
- **BQ-D7** 不自动采纳／不自动发布：adopt 是终态人审，采纳后只进运行面（capability 可被图引用），**不**自动改任何图草稿。

## 5. 验收与反向门

### 5.1 用例（U1477 起，docs/13 预留）

- **U1477**（D76）嵌入配置 GET/PUT 表单：缺省 `enabled=false`（fail-closed）；`token_ttl_seconds` 1–86400 门控；未知 graph 422。
- **U1478**（D76）短链生成：启用后 `POST /api/embeds` 返 token；未启用 422。
- **U1479**（D76）公开只读面：验签通过 → graph 元信息＋最近运行摘要；**不含** decision/密钥/草稿键。
- **U1480**（D76）短链验签失败统一 404（malformed/bad signature/expired 三态同一 404，不区分原因）；跨租户 token 无效 404。
- **U1481**（D76）TTL 生效：过期 token 404；`token_ttl_seconds` 配置化上限 86400。
- **U1482**（D71）`AdapterDefinition` 类型校验：非法 schema 形状/未知 keyword 拒绝；缺 capabilities 拒绝。
- **U1483**（D71）NL 草稿：`POST /api/adapter-drafts` → `ad-` id＋definition JSONB；LLM 失败显式错误（422，不静默）；缺凭据路径 blocked 留证。
- **U1484**（D71）dry-run：base_url 可达 → `reachable=true`；不可达/非 2xx → `reachable=false`＋原因；只读 GET、不落运行账。
- **U1485**（D71）采纳：`PUT decision` admin 可 adopt/dismiss、可改判；已终态重复 → 409；非 admin 403；不存在 404。
- **U1486**（D71）运行时装配：adopted 草稿在 `_runtime_registry` 中出现 `generated:{draft_id}` 工具；dismissed 不出现。
- **U1487**（D71）默认权限：草稿 `permission` 缺省 READ；`auth_type=header/query` 未 admin 确认时 adoption 拒绝（F-P2 最小权限）。
- **U1488**（D71）reset 清档：embed_configs/adapter_drafts 随租户 reset 清空。
- **反向门**（docs/127 §8 F 行"续"的兑现）：① 摘 HMAC 验签 ⇒ U1480 红；② 摘 fail-closed（enabled 缺省 true）⇒ U1477 红；③ 摘 runtime 装配 adopted 过滤 ⇒ U1486 红；④ 摘 F-P2 权限门 ⇒ U1487 红。

### 5.2 Done-when（docs/127 §6 里程碑 F 逐条）

- 客户后台里用一条签名短链打开只读嵌入面（复用审批 HMAC，不新建鉴权形态）✅（U1478–U1481）。
- 图里缺工具时，NL 造出 `AdapterDefinition` 草稿 → dry-run 连通校验 → 人采纳后入注册表 ✅（U1482–U1486）——docs/107「NL 生成适配器配置」旧条闭合。

- **零新依赖／零新错误码／无 ADR**（与 A–E 六批口径一致）。
