## 2. 代码落点

### 2.1 技能推荐：适配器粒度的确定性 top-3

`src/atlas/skills/recommend.py`：

- 技能卡以**适配器**为粒度（`shop/message/database/web-playwright/memory/http`），
  与 05 §1.6“一个技能可以包含多条 capability”对齐；不把单个工具拆成技能。
- `build_skill_catalog(registry)` 只从当前注册表投影，未登记的适配器用 id 兜底；
  不伪造未注册能力。
- 卡片带中英文关键词、优先级和该适配器下真实 `tools`；`recommend_skills(prompt, registry, top_k=3)`
  做确定性子串匹配打分，返回 `id/name/description/score/matched/tools/priority`。
- 同输入同注册表稳定排序（`score desc, priority desc, id asc`）；`top_k=0` 返回空。
- 前端展示 `matched` 命中词，运营能看出“为什么推荐这个技能”，不是黑盒排序。

### 2.2 真实 LLM 生成链

`src/atlas/llm/nl_generate.py`：

- `generate_graph_with_meta()` 保留 `generate_graph()` 兼容入口；真实模型最多 2 次尝试：
  首稿无法解析或 L3 不过时，把 `errors` 作为 repair 提示再生成一次。
- 返回 `generation` 元信息：`mode`（`llm`/`template`）、`model`、`attempts`、`repaired`、
  `compileOk`、失败时 `errors`；离线模板兜底 `mode=template` 明确标注，**不得算成 AI 成功**。
- prod 无模型仍 fail-closed；dev/demo 退款意图可回落模板，但 meta 明示
  `fallbackReason=llm_unavailable_or_invalid`。
- `_MAX_TOKENS=4096`：实测完整退款图约 1.5k tokens，1024 会截断成长流程非法 JSON。
- Prompt 硬约束：节点 id 唯一、edge 两端真实存在、不生成 `start/end` 占位节点、
  condition defaultTarget 与 branch target 互异、`{{路径}}` 必须用真实节点 id；
  `tool_call` 产出统一写 `{{<节点id>.result...}}`；`database/query` 金额写
  `{{<节点id>.result.rows[0].amount}}`；`shop/list_pending_refunds` 金额写
  `{{<节点id>.result.orders[0].amount}}`；全局变量必须写 `{{global.<name>}}`；
  退款场景禁止用 `http/request` 代替 `shop/*`；网页/记忆工具名与参数在 prompt 中列明。
  trigger 只允许一个起点，`schedule` 必须给 5 段 cron（如 `0 9 * * *`），`webhook`
  必须给 `webhookUrl`，结束节点不得建成 trigger，末端不得连回 trigger。

### 2.3 草稿归一化：只修无歧义形状

`normalize_generated_graph()`：

- 强制 `version=1`；节点 id 缺失补 `node-N`、重复加 `-2/-3`；补 `type/name/config/position`。
- 丢弃 source/target 不存在 edge；edge id 去重。
- condition `defaultTarget` 与 branch target 撞车且出边存在另一目标时，改默认目标；
  没有第二个目标不猜，留给 L1/L2。
- 裸全局变量归一：已声明且不与节点 id 冲突的 `{{name}}` → `{{global.name}}`；
  同名节点 id 优先，不误判。
- `retry.on_error` 非法枚举（模型常写 `retry`）收敛为最保守的 `stop`，保留
  `max_retries/timeout` 原值；不静默改成 `continue`。
- condition 的显式 branch 与 `defaultTarget` 同目标时，删除冗余 branch（保留默认路径）；
  只剩零 branch 时不猜，交给 L2/L3。
- 所有 branch 与 `defaultTarget` 都指向同一节点的 condition 是纯固定路由，折叠该节点并
  把入边改指目标；若条件 id 被其他 config 引用则不折叠。
- 非 loop 节点自环直接丢弃；loop 节点回边允许指向自身。
- 不猜其他缺失分支目标、不伪造工具、不自动补审批目标。

2026-11-23 晚补的确定性修复（只为消除格式歧义，不改业务语义）：

- `_repair_condition_expression(s)`：补 `{{path}` 缺失右括号；拆 `{{path != null}}` 为
  `{{path}} != null`；处理 `{{a == 1 && {{b != null}}` 外层多开括号；去掉整段误包的
  `{{a == 1 && b == 2}}`；表达式里裸 dotted 路径补 `{{...}}`；同时作用于 condition 分支
  与 loop `continueExpression`。
- `_qualify_context_refs()`：图里恰好一个 trigger 时，裸 `{{context.payload.*}}` 补成
  `{{<trigger>.context.payload.*}}`；多 trigger 不猜。
- `_normalize_tool_node_type()`：节点 `type` 不在 DSL 支持列表且形如 `adapter/tool` 时，
  改为 `tool_call`，原值放入 `config.tool`；解决模型把工具名误写成节点 type。
- prompt 追加：`ai_decision` 只引用 `{{<节点id>.decision}}` 与 `{{<节点id>.prompt_rendered}}`；
  所有 `{{global.*}}` 必须在 `variables` 声明；数组长度用 `len({{path}})` 且 `len()`
  只能出现在 condition/loop 表达式；wait 不得作为图结束节点；只有 loop 循环体允许回边；
  `tool_call` 统一暴露 `result`；`context.payload` 必须带 trigger id。

这些修复把“括号/路径/节点 type”类错误收敛，但不解决语义错误：不可达节点、`ai_decision`
输出字段越界、编造工具输出字段、漏声明全局变量仍需模型或人工处理。

### 2.4 L3 编译校验

`validate_generated_graph(graph, registry)`：

- `parse_graph` + `validate_graph_report(check_refs=True)`；
- 使用 `tool_output_schemas`（不是 input schema）校验 `{{节点.result...}}` 深路径；
- parse 异常统一 `GRAPH_PARSE_ERROR`；返回 `{ok, errors, codes}`。
- 这里的 L3 是 `dsl.py` 图级校验（环/不可达/引用三码等），不是拉起 LangGraph 实际运行；
  不把“编译通过”冒充“运行成功”。

### 2.5 API 与前端

`POST /api/nl/generate` 返回：

```json
{
  "graph": {...},
  "paramWarnings": ["..."],
  "skills": [{"id":"shop","name":"售后退款","score":9.5,"matched":["退款"],"tools":["shop/..."],"priority":60}],
  "compile": {"ok": true, "errors": [], "codes": []},
  "generation": {"mode":"llm","model":"openai/agnes-3.0-flash","attempts":2,"repaired":true,"compileOk":true}
}
```

前端 `Editor.tsx` 的 NL Modal：

- 生成后不立即关窗，展示来源（真实模型/模板兜底）、模型、尝试次数、是否修复、L3 结果；
- 展示技能 top-3：id、名称、匹配分、命中词、真实工具；
- `mode=template` 用黄色警告明写“不是 AI 生成”，避免把兜底当质量证据；
- 编译错误逐条展示，同时仍把草稿载入画布供人工改；
- 改 prompt 时清空上一次结果，避免旧结果误配新输入。

`apiClient.ts` 增加 `NLSkillRecommendation` / `NLGenerationMeta` / `NLCompileReport` /
`NLGenerateResult` 类型；前端 API 契约测试覆盖请求形状与四个返回字段。

2026-11-23 晚补的前端路径修复：`frontend/src/lib/scope.ts` 新增 `splitRefPath(path)`，
把 `rows[0].status` 拆成 `rows` / `0` / `status`，模板引用校验、tool_call 参数类型校验、
数据依赖边生成三处统一使用。根因是后端已支持数组下标展开，前端把 `rows[0]` 当整段属性，
误报“工具 database/query 的输出中不存在该路径”；修复后画布问题面板由错误变为“无问题”。

## 3. 真实模型探测与修复记录

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 1024 tokens 截断长流程，JSON 不完整 | `max_tokens` 太小 | `_MAX_TOKENS=4096`，注释记录实测 |
| 原始返回以 ``` 结尾导致 JSON 提取失败 | 只按 fenced JSON 解析 | `json.JSONDecoder().raw_decode` 从首个 `{` 解析，容忍尾部解释/代码围栏；失败删 trailing comma 再试 |
| condition 首稿 `defaultTarget` 与 branch target 相同 | 模型自造默认分支 | 有另一出边目标时确定性改默认目标，否则留给 L1/L2 |
| `{{q.result.rows[0].amount}}` 被误判路径不存在 | `_schema_has_path` 不拆数组下标；校验用了 input schema | 新增 `_expand_array_segments`；改 `tool_output_schemas` |
| 裸 `{{customer_email}}` 被当节点引用 | 模型未写 `global.` 前缀 | prompt 明约束 + 已声明变量归一化 |
| 退款场景用 `http/request` 代替 `shop/*` | prompt 未明确场景工具优先级 | prompt 加“禁止用 http/request 代替 shop 退款工具” |
| `retry.on_error="retry"` 解析失败 | 模型自造 retry 语义，DSL 只认 stop/continue/jump_to | 归一化非法枚举为 `stop`，保留重试次数/超时原值 |
| `ai_decision` 缺 `promptTemplate` 解析失败 | 模型不知道 ai_decision 必填字段 | prompt 明写必须给非空 `promptTemplate`，能用 condition 时不要硬塞 ai_decision |
| condition 显式 branch 与 `defaultTarget` 同目标 | 两出口条件被模型写成“成功/失败”+默认失败 | 删除与 default 重复的 branch，保留默认失败路径；等价语义、无猜测 |
| condition 所有分支都指向同一节点 | 模型用 condition 做无意义固定路由 | 折叠 condition、入边改指目标；有 config 引用则跳过 |
| 非 loop 节点自环 | 模型把末端连回自身 | 丢弃自环；loop 回边保留 |

## 6. 边界与未做

- **20 条是回归集，不是质量承诺**：覆盖常见退款/通知/查询/网页/记忆意图，不覆盖所有长尾业务。
- **技能粒度是适配器级**：不是单 capability 级；同一适配器下工具仍由 LLM 选择，top-3 只缩小候选面。
- **L3 通过不等于运行通过**：没有对 20 张图逐一真实执行；副作用/审批/浏览器执行各有 A-01/A-05 证据。
- **只测一个真实模型**：`openai/agnes-3.0-flash`；没有多模型对比、没有人工盲评、没有语义等价评分。
- **模板兜底不算 AI**：`mode=template` 只保证离线可用，评估严格排除。
- **免费额度限流**：评估脚本支持断点续跑；失败归档里保留限流错误，不把限流当模型质量结论。
- **未做**：自动保存生成图、自动发布、生成后自动跑、技能 top-k 可调 UI、单工具粒度技能、
  多轮对话改写、执行反馈再生成。
- **前端验收边界**：已完成真实后端 + 真实浏览器 NL Modal 验收（见 §4.5，证据 `outputs/a06-nl-ui/20-*`、`21-*`）；但浏览器窗口在验收时被缩到 219×811，Modal 动画受 rAF 节流，截图用了强制可见，不是视觉回归门。
